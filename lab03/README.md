*Составьте глоссарий из определений лекции. Проверка отчета будет включать

* **Тип в программировании** - атрибут объекта данных, задающий множество допустимых значений и методы для работы с ними.
* **Статическая типизация** - это подход, при котором типы переменных определяются и проверяются на этапе компиляции программы, и этот тип остаётся неизменным на протяжении всего времени её существования.
* **Динамическая типизация** -  это подход в программировании, при котором типы переменных определяются и проверяются не на этапе компиляции, а во время выполнения программы.
* **Неявная типизация** - это подход в программировании, при котором компилятор или интерпретатор автоматически определяет тип переменной на основе присвоенного ей значения. 
* **Явное преобразование типа** -  метод, преобразующий значение одного типа в такое же или близкое значение другого типа,  если оно указано в программе в виде вызова функции или в виде операции.
* **Неявное преобразование типа** - это автоматическое преобразование данных из одного типа в другой, которое выполняет компилятор или интерпретатор.
* **Сильная типизация** - язык программирования не содержит (почти не содержит) правил неявного преобразования типа.
* **Слабая типизация** - язык программирования содержит большое число правил неявного преобразования типа, допускает каламбуры типизации.

Существуют неявные преобразования между всеми базовыми типами.
**Преобразования с логическими значениями:** 
Преобразование в bool: 0 — false; остальные значения — true.
Преобразование из bool: false — 0; true — 1.
Результат условного выражения в инструкциях ветвления и цикла приводится к логическому типу
Если оператор требует логического значения, то операнды приводятся к логическому типу (логические операции).
**Преобразования при присваивании:**
При вызове функции фактический параметр приводится к типу формального параметра.
При присваивании значение правого операнда приводится к типу левого операнда.
**Преобразование при арифметических действиях:**
Преобразование из вещественных в целочисленные: отсечение дробной части.
Если длины обоих типов меньше int то преобразование к int.
Если типы разной длины, то преобразуется меньший к большему
Если типы равной длины и один знаковый, а другой беззнаковый,  то знаковый приводится к беззнаковому.
Если один целый, а другой вещественный, то целый приводится к вещественному.
Преобразование с символьными типами: по коду символа.
Преобразование из вещественных в целочисленные: отсечение дробной части.

### Задание 4 **(1)**

*Рассмотрите следующий фрагмент программы.*

```
bool x = true, y = false;
auto a = x & y;
std::cout << typeid(a).name() << std::endl;
auto b = x && y;
std::cout << typeid(b).name() << std::endl;
```
Оператор & — это побитовое И. Тип bool неявно преобразуется в int. Затем выполняется побитовое И над двумя int, и результат также имеет тип int. Ключевое слово auto выводит тип из выражения, поэтому a получает тип int.
Оператор && — это логическое И. В отличие от побитового оператора, логический && всегда возвращает значение типа bool, независимо от типов операндов. Результатом true && false является false (тип bool), поэтому auto выводит тип bool.

```cpp
#include <iostream>

int main() {

### Задание 6 **(2)**

Рассмотрите следующий фрагмент программы. 
```
int a = -1, b = 1;
unsigned int c = 1;
std::cout << a*b << std::endl;

* *Объясните работу этой программы, используя правила неявного преобразования типов*
* *Что произойдет, если тип* **int** *заменить на* **short**, а **unsigned int** на **unsigned short**?*
1. Первое выражение: a * b

Обе переменные имеют тип int, поэтому дополнительного преобразования не происходит: -1 * 1 = -1

2. Второе выражение: a * c

Согласно правилам обычных арифметических преобразований, если операнды имеют одинаковый размер, но разную знаковость, знаковый тип неявно преобразуется в беззнаковый. Двоичное представление числа -1 в дополнительном коде состоит из всех единиц(2 в 32 степени). Когда компилятор начинает интерпретировать этот же набор битов как unsigned int, он читает его не как -1, а как максимально возможное положительное число для этого типа.

3. Если заменить типы на short и unsigned short

```cpp
short a = -1, b = 1;
unsigned short c = 1;
```

При арифметической операции оба типа сначала продвигаются до int, поскольку их диапазоны помещаются в int на обычной реализации C++.
Компилятор проверяет, может ли обычный int вместить все значения unsigned short. Поскольку unsigned short имеет диапазон от 0 до 65535, а 32-битный int может хранить числа до ~2 миллиардов, оба операнда (a и c) повышаются до знакового int.

### Задание 7 **(2)**
*Рассмотрите следующий фрагмент программы.*
```
int x = 7, y = 4;
long double d = 0.25;
cout << (x / y) / d << endl;
cout << (x / d) / y << endl;
long a = 200000, b = 200000;
long long c = 200000;
std::cout << (a * b) * c << std::endl;
std::cout << a * (b * c) << std::endl;
```
*Почему изменения порядка действий приводит
к изменению результата? Объясните работу этой программы, используя правила неявного преобразования типов*
1. Выражение (x / y) / d

    1: Вычисляется выражение в скобках x / y. Оба операнда имеют тип int. Согласно правилам C++, деление двух целых чисел дает целое число. Дробная часть просто отбрасывается.
        7 / 4 = 1 (тип int).
    2: Вычисляется 1 / d. Здесь операнды имеют типы int и long double.
    Правило неявного преобразования: Если в операции участвуют int и long double, тип int неявно повышается до long double.
        1 превращается в 1.0L.
        1.0L / 0.25L = 4.0.
2. Выражение (x / d) / y
    1: Вычисляется x / d. Операнды: int и long double.

    Правило неявного преобразования: x повышается до long double перед выполнением деления.
        7.0L / 0.25L = 28.0L (тип long double).

    2: Вычисляется 28.0L / y. Операнды: long double и int.

    Правило неявного преобразования: y повышается до long double.
        28.0L / 4.0L = 7.0.
3. ВЫражение (a * b) * c
    a * b сначала вычисляется как long: 200000 * 200000 = 40 000 000 000
    Это больше максимального значения 32-битного long, поэтому происходит переполнение уже на первом умножении. После этого полученное значение участвует в умножении на long long.
4. Выражение a * (b * c)
    b * c сразу выполняется как long long, поэтому переполнения long нет. Затем a также приводится к long long, и вычисляется произведение в более широком типе.

*Для каких значений целочисленных переменных* **x**, **y** ,**z** *результатом
вычисления следующего выражения будет истина? Перечислите* **все** *случаи.
Объясните работу этой программы, используя правила неявного преобразования типов*

```
(x == y) + (x == z) == true
```
Выражение (x == y) + (x == z) == true использует два неявных преобразования:

1. Целочисленное повышение c bool до int при сложении. Результаты сравнений (true/false) превращаются в 1/0, поэтому сумма может принимать значения 0, 1 или 2.
2. Повышение с bool до int при сравнении суммы с true. Правая часть true превращается в 1, поэтому равенство выполняется только когда сумма равна 1.
Чтобы результат являлась истина, нужно чтобы одна из частей выражения, или же обе, принимали значение true.
### Задание 9 **(2)**

*Проверьте работу логического выражения*
```
x==y==z
```
*в языках* **Python**, **Java**, **C++** *для
целочисленных переменных* **x**, **y**, **z**.
*Объясните результат для каждого из языков.*
В Python это цепочечное сравнение:

```python
x = 6
y = 3
z = 4
result = x == y == z
print(result)
```

эквивалентно:

```python
(x == y) and (y == z)
```

Поэтому выражение истинно тогда и только тогда, когда: x = y = z.

#### Java

В Java сравнение выполняется слева направо. После первого сравнения x == y получается значение типа boolean. Затем программа фактически пытается сравнить этот boolean с z, имеющим тип int:

```java
public class main {
    public static void main(String[] args) {
        int x = 6, y = 4, z = 1;
        boolean b = (x == y) == z;
        System.out.print(b);
    }
}
```

Такое сравнение недопустимо, поэтому программа не компилируется.

#### C++

В C++ выражение также разбирается слева направо:

```cpp
#include <iostream>
int main(){
    int x = 5, z = 2, y = 7;
    bool b = (x == y) == z;
    std::cout << b;
}
```

Результат x == y имеет тип bool. При сравнении с z bool преобразуется в целое значение по принципу: false в 0, trur в 1

Оно истинно в двух случаях:

x == y и z == 1 или x != y и z == 0
