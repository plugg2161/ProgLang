## Задание 2

### Исходные фрагменты

**C++:**
```cpp
int main() {
   int a=1, b=2;
   int c=a++b;
   return 0;  
}
```

**Python:**
```python
a=1
b=2
c=a++b
```


- **C++**: ошибка компиляции. Сообщение: `error: expected ',' or ';' before 'b'`.
- **Python**: программа выполняется успешно, `c` равно `3`.


- **Токены C++**: `int`, `main`, `(`, `)`, `{`, `int`, `a`, `=`, `1`, `,`, `b`, `=`, `2`, `;`, `int`, `c`, `=`, `a`, `++`, `b`, `;`, `return`, `0`, `;`, `}`.
- **Токены Python**: `a`, `=`, `1`, `b`, `=`, `2`, `c`, `=`, `a`, `+`, `+`, `b`.

В C++ работает правило максимального совпадения: компилятор объединяет два символа `+` в один токен постфиксного инкремента `++`. В результате код интерпретируется как `c = a++ b;` — между `a++` и `b` нет оператора, что и вызывает синтаксическую ошибку.

В Python оператора `++` не существует. Компилятор разбивает `++` на два отдельных токена `+`. Выражение читается как `a + (+b)` — бинарный плюс и унарный плюс, что корректно и даёт `1 + 2 = 3`.

## Задание 3


```cpp
int main() {
   int a=1, b=2;
   int c=a+++b;
   return 0; 
}
```

После исполнения: `a = 2`, `b = 2`, `c = 3`.

Токены: `a`, `++`, `+`, `b`.

По правилу максимального совпадения первые два плюса образуют токен `++`, третий остаётся бинарным `+`. Выражение читается как `(a++) + b`:
1. Вычисляется `a++` — возвращается старое значение `a`, затем `a` увеличивается до 2.
2. К возвращённому значению прибавляется `b`.
3. Результат присваивается `c`. `c` = 3.

Разбиение пробелами можно изменить. Если написать `a + ++b`, токены будут: `a`, `+`, `++`, `b`. Выражение читается как `a + (++b)`: сначала `b` увеличивается до 3, затем складывается с `a`. Новый результат: `a = 1`, `b = 3`, `c = 4`.

## Задание 4

### Круглые скобки `()`

Являются оператором в случаях:
- вызов функции: `func(x)`
- приведение типа: `(int)y`

Не являются оператором:
- группировка выражений: `(a + b) * c`
- объявление функции: `void f(int x)`

### Квадратные скобки `[]`

Являются оператором:
- индексация (доступ к элементу): `arr[i]`

Не являются оператором:
- объявление массива: `int arr[10]`

## Задание 5

### Программа

```python
print(*map(sum, zip(
    *[map(int, input().split()) for i in (1, 2, 3)]
    )))
```

- **Ключевые слова**: `for`, `in`
- **Идентификаторы**: `print`, `map`, `sum`, `zip`, `int`, `input`, `split`, `i`
- **Литералы**: `1`, `2`, `3`
- **Операторы**: `*`, `.` (доступ к атрибуту), `(`, `)`, `[`, `]`

1. `input()` — без параметров.
2. `.split()` — вызывается на строке (результат `input`), без параметров.
3. `int(x)` — вызывается внутри `map`, параметр — строка.
4. `map(int, iterable)` — параметры: функция `int` и результат `split()`.
5. `zip(*iterables)` — параметр: распакованный список из трёх объектов `map`.
6. `sum(iterable)` — вызывается внутри внешнего `map`, параметр — кортеж чисел из `zip`.
7. `print(*objects)` — параметр: распакованный результат внешнего `map`.

### Что делает программа

Программа читает 3 строки ввода, каждая из которых содержит числа, разделённые пробелами. Преобразует их в целые числа, формируя матрицу 3×N. С помощью `zip(*...)` матрица транспонируется (числа группируются по столбцам). Функция `map(sum, ...)` вычисляет сумму каждого столбца. `print(*...)` выводит эти суммы через пробел.

## Задание 6

- `//` — однострочный комментарий (до конца строки).
- `/* ... */` — многострочный (блочный) комментарий.

1. `cout<<"Hello /* Это комментарий */ world";`
   **Верно.** Последовательность `/*...*/` находится внутри строкового литерала и не распознаётся как комментарий.

2. `// /*` / ` Это комментарий` / `*/`
   **Неверно.** `//` комментирует только первую строку. Одинокий `*/` в конце вызовет ошибку компиляции.

3. `/* Я комментирую /* комментарий */ */`
   **Неверно.** Вложенные комментарии в C++ запрещены. Первый `*/` закроет комментарий, второй вызовет ошибку.

4. `// Я комментирую программы /* комментарий */`
   **Верно.** Вся строка является корректным однострочным комментарием.

5. `/* Я комментирую свои программы` / `// Это комментарий до конца строки */` / `*/`
   **Неверно.** Первый `*/` закроет блок комментария. Второй `*/` окажется в коде и вызовет ошибку.

## Задание 7

Согласно стандарту C++ (N4659, Annex A.5), существует 4 вида инструкций циклов (`iteration-statement`):

### 1. Цикл `while`

Правило:
```
while ( condition ) statement
```

Формат записи: ключевое слово `while`, в круглых скобках условие `condition`, далее инструкция `statement`.

Пример:
```cpp
int x = 1;
while (x < 1000) {
    cout << x;
    x *= 2;
}
```

### 2. Цикл `do-while`

Правило:
```
do statement while ( expression ) ;
```

Формат записи: ключевое слово `do`, далее инструкция `statement`, затем ключевое слово `while`, в круглых скобках выражение `expression` и точка с запятой.

Пример:
```cpp
int x = 1;
do {
    cout << x;
    x *= 2;
} while (x < 1000);
```

### 3. Цикл `for`

Правило:
```
for ( init-statement condition_opt ; expression_opt ) statement
```

Формат записи: ключевое слово `for`, в круглых скобках инициализация `init-statement`, необязательное условие `condition`, точка с запятой, необязательное выражение `expression`, далее инструкция `statement`.

Пример:
```cpp
for (int i = 0; i < 10; ++i) {
    cout << i;
}
```

### 4. Цикл `for` по диапазону

Правило:
```
for ( for-range-declaration : for-range-initializer ) statement
```

Формат записи: ключевое слово `for`, в круглых скобках объявление переменной `for-range-declaration`, двоеточие, инициализатор диапазона `for-range-initializer`, далее инструкция `statement`.

Пример:
```cpp
std::vector<int> v = {1, 2, 3};
for (int x : v) {
    cout << x;
}
```
